# Centwise - Subscription Manager (React)

## Run on Localhost

1. Extract this zip folder.
2. Open terminal inside the `centwise-react` folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the local dev server:
   ```bash
   npm run dev
   ```
5. Open the localhost URL shown in your terminal (usually `http://localhost:5173`).
